# Cricket Data Analysis Dashboard

An interactive Power BI dashboard for cricket player and match performance.
Project period: Jul 2025 – Aug 2025.

## Overview

- Cleaned raw cricket datasets into structured data for reporting
- Built charts and reports that show performance trends
- Made player comparison easier with clear visuals

## Tech Stack

- Power BI
- Data Cleaning
- Data Visualization
- Data Analysis

## What the Dashboard Shows

- Player performance
- Match performance
- Performance trends
- Player comparison
